## 🎯 About This App

Deja lets you view DjVu files on your computer. Many people use this format for scanned documents or books. This app opens these files quickly. You do not need to wait for pages to load. The design focuses on simplicity. You open the file, you read the content, and you move to the next page. Everything functions in a way that makes sense to a new user.

## ⚙️ System Requirements

You need a computer running Windows 10 or Windows 11. The app works best with at least 4GB of RAM. Make sure you have enough storage space for your documents. You do not need special hardware to run Deja. The app handles heavy, high-resolution scans without slowing down your computer.

## 🚀 Using Deja

The user interface follows a standard layout. You find the main menu bar at the top of the window. Use the File menu to pick a document from your computer. Once the file loads, you use the scroll wheel on your mouse to move through pages. You can also use the arrow keys on your keyboard. 

The zoom tool helps you see small text or fine details in images. Click the plus button to zoom in and the minus button to zoom out. If a scan appears sideways, click the rotate button. This flips the page to the correct angle.

You can set the app to open specific files automatically. Right-click any DjVu file on your computer and select Open with. Choose Deja from the list. Check the box that says Always use this app to open .djvu files. Now, every document opens instantly when you double-click it.

## 🛡️ Privacy and Safety

This software keeps your files on your computer. It does not send your documents to the internet. You do not need an account to use the features. We do not track your reading habits. Your documents remain private and secure on your local hard drive at all times.

## 🛠️ Troubleshooting

If the app fails to open, restart your computer. Sometimes Windows needs a refresh to register new software. If you cannot open a specific file, check the file extension. Ensure the file ends in .djvu. If the file is broken, the app will show an error message. Try to download the file again from your source.

If you see a warning from Windows about the app, click More info. Then click Run anyway. Windows sometimes flags new files that it does not recognize. This is a common security feature. Deja remains safe for your system.

## 🏗️ Performance Tips

Large documents might take a moment to index when you first open them. This happens only once per file. After the app processes the file, your future sessions stay fast. If your computer feels slow while you read, close other programs that consume a lot of memory. Deja prioritizes speed, so it performs best when it has enough space to operate.
